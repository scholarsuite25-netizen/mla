# Biru Design System Rules for MLA

## Design Tokens & Classes
- **Canvas Background**: `bg-[#FAFAFD]`
- **Text Color**: `text-slate-800` (headings `text-slate-900`)
- **Card Styling**: `bg-white rounded-2xl border border-slate-200/90 p-6 shadow-sm hover:border-cyan-400/60 hover:shadow-md transition-all`
- **Banner Gradient**: `bg-gradient-to-br from-[#120D42] via-[#161152] to-[#241468] text-white`
- **Buttons (Primary Action)**: `rounded-lg bg-[#00D2FF] px-6 py-2.5 text-xs sm:text-sm font-bold text-[#0A0E2A] shadow-md shadow-cyan-500/20 hover:bg-[#38BDF8] transition-all`
- **Buttons (Secondary Action)**: `rounded-lg border border-slate-200 bg-white px-5 py-2.5 text-xs sm:text-sm font-semibold text-slate-700 hover:border-cyan-400 transition-all`
- **Pill Badges**: `inline-flex items-center gap-1.5 rounded-full border border-cyan-400/30 bg-cyan-50 px-3 py-1 text-xs font-semibold text-[#0284C7]`
- **Inputs**: `w-full rounded-xl border border-slate-200 bg-white px-3.5 py-2.5 text-xs sm:text-sm text-slate-800 placeholder:text-slate-400 focus:border-cyan-400 focus:outline-none focus:ring-1 focus:ring-cyan-400 transition-all`
