# Do-It-For-Me Autonomous Workflow

When the user gives an instruction or feature request:
1. **Analyze & Plan Autonomously**: Break down requirements into components, routes, and styles without asking technical questions.
2. **Execute Full Edits**: Directly modify the relevant files using modern, clean TypeScript and Tailwind CSS patterns.
3. **Self-Verification**:
   - Run `npm test` or build check.
   - If tests fail, automatically debug and resolve the errors without asking the user.
4. **Summary**: Provide a plain English executive summary of what was accomplished and how to view or test it.
